HOW DO I CONNECT TO UNSTABLEMC?

Follow these simple steps to join the server on Minecraft Java Edition:

  1. Open Minecraft Java Edition (Fabric/Vanilla).
  2. Go to Multiplayer and click Direct Connection or Add Server.
  3. Type in the server address: unstablemc.pixelforge.gg
  4. Click Join Server and dive into the chaos!
